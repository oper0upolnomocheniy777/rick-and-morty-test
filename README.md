# Rick and Morty — список персонажей

Тестовое задание: страница со списком персонажей из Rick and Morty API.

## 🚀 Запуск 

**Клонировать репозиторий**

```
git clone https://github.com/oper0upolnomocheniy777/rick-and-morty-test.git
cd rick-and-morty-test
```

**Установить зависимости**

```
npm install
```
**Запустить dev-сервер**

```
npm run dev
```
Откройте http://localhost:5173 — страница запустится.
